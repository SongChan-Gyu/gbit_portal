# 전체 기능 테스트·데이터 정합성 가이드

## 1. 데이터 정합성 검증 (자동)

배포 후 또는 시드/마이그레이션 후 아래 스크립트로 DB 정합성을 확인할 수 있습니다.

```bash
# 휴가 규정·결재·할당 usedDays 등 휴가 도메인 검증
npx tsx scripts/verify-leave-policy.ts

# User/Employee/LeaveType/할당 usedDays/결재 단계 등 기본 정합성
npx tsx scripts/verify-data-integrity.ts
```

- 두 스크립트 모두 **실패 시 exit code 1**로 종료하므로 CI에서 사용 가능합니다.
- 로컬·클라우드 동일하게 `DATABASE_URL`이 가리키는 DB 기준으로 실행됩니다.

## 3. 클라우드 배포 시 주의사항

- **엑셀 양식 다운로드**: 브라우저에서 `window.open(..., "_blank")`만 쓰면 일부 환경에서 파일이 열리기만 하고 다운로드되지 않을 수 있습니다.  
  인사 관리 > 사원 관리 > “엑셀 템플릿 다운로드”는 **fetch + Blob + `<a download>`** 방식으로 구현되어 있어, 로컬·클라우드 모두 동일하게 다운로드가 되어야 합니다.  
  다운로드가 안 되면 세션(쿠키) 만료·권한(PM/ADMIN)을 확인하세요.
- **네이버 지도**: 숙소 정보 페이지의 지도는 네이버 지도 embed iframe을 사용합니다.  
  네이버 정책으로 인해 일부 환경에서 iframe이 차단될 수 있으며, 이 경우 “네이버 지도에서 보기” 링크로 새 탭에서 지도를 열 수 있습니다.

## 4. 정합성 검증이 실패할 때

- `verify-leave-policy.ts` 실패: 휴가 유형 시드·귀속연도 할당 시드 재실행 또는 관리자 화면에서 설정 확인.
- `verify-data-integrity.ts` 실패: User/Employee 없음 → 시드 실행; usedDays 불일치 → 휴가 승인/취소 이력과 할당 테이블 재계산 필요 시 관리자 기능 또는 수동 보정.
