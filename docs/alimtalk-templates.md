# 카카오 알림톡 템플릿 (GBIT Portal)

코드 발송 로직: `src/lib/kakao.ts`.  
중계 서비스(알리고·비즈고·NHN 등)에 **템플릿 코드가 아래와 동일**해야 `tpl_code` 매칭됩니다.  
변수는 발송 시 `#{변수명}` 형태로 치환됩니다(카카오 검수 시에도 동일 표기로 등록).

---

## 요약표

| 템플릿 코드 | 용도 |
|-------------|------|
| `LEAVE_REQUEST` | 휴가 결재 요청 → 결재자 |
| `LEAVE_WITHDRAWN` | 휴가 신청 철회(승인 전) → 결재자 |
| `LEAVE_RESULT` | 휴가 승인/반려 결과 → 신청자 |
| `JEJU_REQUEST` | 제주 숙소 예약 결재 요청 → 결재자 |
| `JEJU_APPROVED` | 제주 숙소 승인 → 신청자 |
| `JEJU_REJECTED` | 제주 숙소 반려 → 신청자 |
| `JEJU_CANCEL_REQUESTED` | 제주 숙소 취소 요청 → 결재자 |
| `JEJU_CANCELLED` | 제주 숙소 취소 완료 → 신청자 |
| `INVITE_REGISTER` | 회원가입 초대(선택) → 초대받은 사원 |

---

## 1. LEAVE_REQUEST (휴가 결재 요청)

**변수:** `결재자명`, `신청자명`, `휴가유형`, `시작일`, `시작요일`, `종료일`, `종료요일`

**제목(알리고 subject):** 휴가 결재 요청

**본문:**

```
[GBIT Portal]
#{결재자명}님, 휴가 결재 요청이 도착했습니다.

- 신청자: #{신청자명}
- 휴가유형: #{휴가유형}
- 기간: #{시작일}(#{시작요일}) ~ #{종료일}(#{종료요일})

GBIT Portal에서 확인 후 처리 부탁드립니다.
본 메시지는 발신 전용입니다.
```

---

## 2. LEAVE_WITHDRAWN (휴가 신청 철회 안내)

**변수:** `결재자명`, `신청자명`, `요약`

**제목:** 휴가 신청 철회 안내

**본문:**

```
[GBIT Portal]
#{결재자명}님, #{신청자명}님이 휴가 신청을 철회했습니다.

#{요약}

결재함에서 해당 건은 더 이상 처리할 필요가 없습니다.
본 메시지는 발신 전용입니다.
```

---

## 3. LEAVE_RESULT (휴가 처리 결과)

**변수:** `신청자명`, `처리결과`, `처리코멘트`  
(`처리결과` 예: 승인, 반려 / `처리코멘트` 없으면 코드에서 `-` 전달)

**제목:** 휴가 처리 결과

**본문:**

```
[GBIT Portal]
#{신청자명}님, 신청하신 휴가가 #{처리결과}(으)로 처리되었습니다.

#{처리코멘트}

GBIT Portal에서 상세 내역을 확인해 주세요.
본 메시지는 발신 전용입니다.
```

## 검수·연동 시 참고

- 본문은 `src/lib/kakao.ts`의 `templates` 객체와 **글자 단위로 같게** 두는 것이 안전합니다. 문구를 바꾸면 **중계 콘솔 템플릿도 동일하게** 수정하세요.
- 테스트: `.env`에 `ALIMTALK_ALLOWED_RECEIVER`를 본인 번호만 넣으면 그 번호로만 발송됩니다(그 외 SKIPPED).
